# Practical work 1. C# basics. Console application

Variant 1 - Test results statistics.

Console app with a menu: add a score (0-100), show all scores, average,
highest/lowest with positions, distribution by category.
Empty array is handled: every operation except adding prints "No data".

Run: open `NET_PR1_Klopov.sln` in Visual Studio (or `dotnet run --project TestStatistics`).
Requires .NET 10 SDK.
